## 1. 背景与目标

北京中考填志愿时，通勤便利度是除教学水平外的硬性决策因素。现有渠道只提供学校地址，家长需逐所手动搜索对比。

**目标**：输入家庭地址 + 招生区或学校名 → 一屏给出候选高中的距离、用时、路线。
**不做**：教学水平评估、分数线匹配、择校综合咨询。

## 2. 目标用户与场景

**用户**：北京中考考生家长（90%）+ 考生本人。城区/近郊居住，孩子初三面对 4-7 月志愿窗口。
**场景**：①填报截止前对 5-10 所备选做最终通勤对比 ②成绩前按预估分档批量看通勤 ③周末参观学校前查看片区分布。

## 3. 功能需求

| 编号 | 功能 | 验收 |
|---|---|---|
| F-01 | 家庭地址输入（高德 placeSearch 联想） | 输入≥2字符后 ≤0.5s 出候选；附"地图选位置"按钮 |

| F-10 | API 限额降级 | 全日耗尽 → 顶部 banner + 保留直线距离视图 |

## 4. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 首屏可交互 ≤2s；列表首渲 ≤3s；可见卡片精确通勤 ≤6s；单路线渲染 ≤2s |
| 兼容 | iOS Safari 14+ / Android Chrome 90+ / PC 主流浏览器最新版；移动优先响应式（375px 基准） |
| 隐私 | 家庭地址仅活在浏览器内存与 localStorage；不上传任何自建后端；经纬度发送高德不附身份信息 |
| 安全 | 高德 Key 配域名白名单 + 每日 20000 次上限 |
| 可维护 | 数据按区分割 JSON；每条带 lastVerified；无构建工具，浏览器直开 |

## 5. 数据模型

**学校 School 核心字段**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 唯一标识 |
| name / shortName / aliases | string / string / string[] | 全称、简称、别名词典（供 F-12 搜索） |
| isBranch / parentSchool | bool / id | 分校标识 + 关联本部 |
| district | enum | haidian / xicheng / chaoyang / dongcheng |
| address / lng / lat | string / float / float | 地址与经纬度 |
| type | enum | public / private / international-dept |
| admissionScope | enum | district（区内招生）/ citywide（全市统招） |
| lastVerified | string | 上次校对（YYYY-MM） |

**分校处理**：每校区独立条目，列表平铺加 tag，招生范围按实际归属判断（不继承本部）。
**数据来源**：AI 整理首版样本 → 用户校对入库；每年 3-5 月人工 review；页面"反馈"入口收报错。

**高德接口映射**

| 产品功能 | 高德接口 | 关键字段 |
|---|---|---|
| 地址联想 | placeSearch | tip.location |
| 地址校验 | geocoder | adcode |
| 驾车路径 | driving | distance, duration |
| 公共交通路径 | **Transfer**（综合换乘，含公交/地铁/市郊铁路） | distance, **duration**（排序依据） |
| 骑行路径 | riding | distance, duration |

## 6. 关键交互流程

**流程 1 · 首查**：输地址 → 选区 → adcode 校验 → 加载区 JSON → Haversine 算直线距离升序 → 可见卡片并发调路径规划。
**流程 2 · 切换方式**：tab 切换 → 列表保持直线距离排序 → 可见卡片用时 loading → 并发调新接口 → ≤3s 回填。
**流程 3 · 看路线**：点"看路线" → 全屏地图 → 绘路径+节点 → 关闭返回，列表状态保留。
**流程 4 · 学校名搜索**：搜"四中" → 命中北京四中 → 直接进入该校详情，跳过选区。

## 7. 异常与降级

| 异常 | 处理 |
|---|---|
| 地址识别失败 | toast 换更具体地点，按钮置灰 |
| 非北京地址 | toast"仅支持北京市内地址" |
| 单校路径规划失败 | 该卡片用时显示"-"，不阻塞其他 |
| 全日额度耗尽 | banner + 保留直线距离视图 |
| 网络断开 | toast"网络异常"，保留已加载结果 |
| localStorage 不可用 | 静默降级，当次会话功能正常 |

## 8. 边界与非目标

不做：教学评分 / 分数线 / 师资介绍 / 用户登录 / 跨设备同步 / 中职职高 / 纯国际学校 / 北京外城市 / 原生 App / 小程序。

## 9. 未决事项
